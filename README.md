# PopBar

为 Windows 自用开发的原生划词工具条，交互参考 [panjie/omapop](https://github.com/panjie/omapop)。使用 C#、WPF、Win32 和 UI Automation 实现，不依赖 Electron、Python 或浏览器后台。

## 运行

最新版本见 [Releases](http://git.fnst.cn.fujitsu.com/panjie/popbar/-/releases)，当前为 [v0.1.0](http://git.fnst.cn.fujitsu.com/panjie/popbar/-/releases/v0.1.0)。

解压 `PopBar-win-x64.zip`，双击 `PopBar.exe`。精简发布包不包含 .NET 库，适用于 Windows 10/11 x64，需要 **.NET 8 Desktop Runtime（Windows x64）**。启动器会自动检查运行时，缺少时显示安装提示并提供下载入口；安装后重新打开 PopBar 即可。也可从 [微软官方下载页](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)选择 **.NET Desktop Runtime → Windows → x64**，无需安装 SDK；普通 .NET Runtime 或 .NET Framework 不能代替 Desktop Runtime。

首次启动显示设置窗口；关闭设置后仍在系统托盘运行。双击托盘图标打开设置，右键可暂停或退出。重复启动不会创建第二个监听进程。

界面默认跟随 Windows 显示语言，支持简体中文、日语和英语，其他语言使用英语。也可在“设置 → 常规 → 界面语言”手动选择，保存后立即生效。语言设置适用于界面文字，已有提示词内容和 AI 回答语言由提示词决定。

在“设置 → 常规 → 启动”勾选“登录 Windows 时启动 PopBar”并保存，即可在当前用户登录后自动启动到系统托盘。移动 `PopBar.exe` 后，请关闭并重新启用此选项以更新启动路径。

1. 在支持辅助功能的应用中，拖动选中文字、双击选词或 Shift 点击扩展选区，鼠标附近会显示工具条。
2. 自动识别不到时，选中文字后按 **Ctrl + Alt + Space**。如果应用不提供选区，该快捷键会尝试临时 Ctrl+C 取词，并尽力还原原剪贴板。
3. 点击 **复制 / 剪切 / 粘贴 / 搜索**、自动出现的智能按钮，或一个 AI 提示词按钮。
4. 点击工具条外、按键、滚动或切换窗口可收起工具条。选择时按住 Win 可抑制弹出。

Teams、Outlook、Word、Excel、PowerPoint、Notion、Adobe Acrobat / Reader、Foxit PDF Reader / Editor、Edge 和 Opera 已预设为优先在下方显示 PopBar。打开“设置 → 工具条位置”可调整默认位置和各应用的位置，也可输入可执行文件名来添加自定义应用。移除应用规则后，该应用使用默认位置。浏览器规则适用于该浏览器中的所有网页，靠近屏幕边缘时 PopBar 会自动换边。

剪切、粘贴仅在能够确认选区可编辑时出现。打开链接支持整段 HTTP(S) 地址和裸域名；文件位置支持完整存在的本地路径。路径和网址沿用原有按钮，不参与智能按钮识别。

本地规则可以识别以下智能操作：

所有智能按钮统一放在工具条最右侧（设置按钮之后），用加宽留白和强调色分隔线与其他按钮隔开；没有智能按钮时不显示该分隔线。

- **计算**：例如 `128 * 0.85`，支持加减乘除、括号、正负号、整数次幂 `^`、后缀百分号 `%`（`200 * 15%` 为 30），以及 `×` / `÷`。使用十进制运算，表达式限 256 字符；不会执行代码。除零或无效表达式在预览中提示。
- **单位转换**：识别 `72°F`、`25℃`、`300 K`、`2.5kg` 等数量，也支持句子中的多个数量。温度在摄氏度、华氏度、开尔文之间转换；长度支持 mm / cm / m / km / in / ft / yd / mi，重量支持 mg / g / kg / lb / oz，容量支持 mL / L / US gal（美制加仑），并支持常见中文单位名。预览列出同类单位的换算结果，最多处理 20 个数量；低于绝对零度的温度会提示错误。不解析速度、面积等复合单位，也不将“5 ft 10 in”等多个数量自动相加。
- **JSON 格式化**：识别有效的 JSON 对象或数组，也支持 `json` 代码块；预览中可切换格式化 / 压缩，保留 Unicode 文字。
- **汇率转换**：默认启用，从文字中识别金额和币种，例如 `$100`、`100美元`、`2万日元`、`EUR 1,234.50`、`价格 100`。支持 CNY、JPY、USD、EUR、GBP、HKD、TWD、KRW、AUD、CAD、CHF、SGD，最多处理前 20 个金额。数字使用小数点、逗号千位分组，支持十 / 百 / 千 / 万 / 亿 / 兆和 k / m 数量后缀，以及日文财务写法（例如 `500百万円` = 500,000,000 JPY、`3千万円` = 30,000,000 JPY、`1億2000万円` = 120,000,000 JPY）。支持全角数字；复合金额按递减的数量级累加，不通过 AI 猜测金额。
- **执行命令**：支持常见命令（如 `git`、`dotnet`、`npm`、`python`、`docker`、`dir`）和 PowerShell 的常见 `Verb-Noun` 命令。支持去除 `PS C:\work>` / `C:\work>` 提示符，以及单行 `powershell` / `cmd` Markdown 代码块。仅识别单条完整命令，不从说明段落中猜测命令，也不执行多行脚本。PowerShell 命令使用 Windows PowerShell，其他命令使用 CMD；相对路径以 PopBar 的工作目录为准。

悬停智能按钮可查看完整目标；**只有点击后才打开或执行**。命令在可见终端运行并保留输出，不自动提权。识别常见命令名不代表校验命令安全性，点击前请确认目标和参数。普通文本仍可搜索。默认搜索使用 Google，可在设置中改成包含 `{text}` 的 HTTPS 地址，例如 `https://www.bing.com/search?q={text}`。

转换结果使用独立的纯文本预览，支持复制；原选区可编辑时提供“替换原文”，替换前仍会验证原选区。不会自动修改剪贴板、执行结果中的代码或打开其中的链接。文件路径和网址仍只显示原有按钮。输入上限 64K 字符。

“设置 → 智能按钮”可关闭汇率按钮，或选择默认目标 **CNY（人民币）/ JPY（日元）/ USD（美元）**，默认为人民币；预览中也可临时切换目标。默认源币种用于 `¥` / `￥` 和“价格 100”等币种不明确的金额，默认 CNY；`$` 按 USD、`元` 按 CNY、`円` 按 JPY。结果会标明对不明确币种采用的假设。

配置 AI 模型后，工具栏先显示本地识别的操作，同时在后台将选中文字（最多 8192 字符）发送给配置的 AI 服务。识别到本地未发现的金额、算式、单位或 JSON 后，工具栏右侧会追加对应按钮。例如选中“売上は五億円です”后，识别成功会显示 **汇率转换**，点击后查询参考汇率。关闭工具栏或重新选词会取消旧请求。可在“设置 → 智能按钮”关闭自动 AI 分析、编辑后台提示词或恢复默认提示词。PopBar 会为提示词附上固定的输出格式要求。

汇率仅在点击后通过 HTTPS 从 [Frankfurter](https://frankfurter.dev/) 获取，不需要 API Key，只发送源币种和目标币种代码，不发送选中文字或金额。结果显示参考汇率、数据日期与来源，日元取整数，其余目标保留两位小数；实际兑换以银行或支付平台为准。汇率在内存中缓存 1 小时，网络失败不会伪造结果或使用过期缓存，窗口提供重试。计算、JSON 和单位转换全部在本机完成。

终端默认需要按住 Shift 划词，且必须由终端公开选区；不会对终端执行 Ctrl+C 兜底，以免中断命令。工具条不抢输入焦点；首次 AI 预览或设置打开时会取得正常窗口焦点。

Teams/WebView2 的跨进程文本控件通过 UI Automation 父链验证归属，不再要求正文与主窗口进程 ID 相同。Windows Terminal 等 WinUI 应用在鼠标命中宿主面板时会尝试同窗口、鼠标位置内的焦点文本控件；划词开始或结束时按着 Shift 即可，选区尚未更新时会短暂重试。应用若未公开选区或以更高权限运行，仍可能无法自动取词。

## AI 配置

自定义 Nerd Font 图标当前限定使用 JetBrainsMono 系列（NF、NFM、NFP 及 NL 变体），自动选择优先使用 `JetBrainsMono NF`。字体需安装在本机，安装后重启 PopBar。

在设置中填写：

- **API 基础地址**：如 `https://api.deepseek.com/v1`、`https://api.openai.com/v1`，或你使用的 OpenAI 兼容网关地址。不要填写最后的 `/chat/completions`。
- **模型 ID**：按服务商或本地服务提供的实际名称填写；不预设模型以免与账户权限不符。
- **DeepSeek Flash 思考模式**：使用官方接口时默认关闭，以缩短正文等待时间。需要时可在 AI 服务设置中开启。
- **API Key**：已保存的密钥以掩码显示，并通过 Windows DPAPI 加密存储。清空输入框并保存即可删除密钥。仅本机 HTTP 地址允许明文传输，远程服务需要 HTTPS。
- **提示词按钮**：默认翻译、解释、润色；可以修改、添加和删除，最多显示 12 个。`{{text}}` 原样替换为选中文字；未写占位符时选中文字附加到末尾。

在提示词列表中拖动条目可以调整顺序，保存后会应用到划词工具条。

点击 AI 提示词按钮或发送追问会发起对应请求。预览支持流式输出、停止、复制、替换原文和连续追问。初始结果完成后显示“追问”按钮；点击后当前窗口显示输入框并停用失焦自动关闭，不会重新生成初始回答。追问会携带当前窗口内的完整对话；Enter 发送，Shift+Enter 换行。不会自动复制或替换，停止/失败会保留部分文字并标记未完成。替换前激活原窗口，重新核对原控件、选区位置、文字和可编辑状态；不能确认时请手动复制。替换成功后结果保留在剪贴板中。

当前版本支持 **Chat Completions 兼容协议**，不是 OpenAI Responses、Claude 原生或 Gemini 原生协议。使用这些服务需要它们的兼容接口或兼容网关。预览以可选择的富文本渲染 Markdown，复制与替换使用渲染后的纯文本。

AI 请求整体限时 180 秒，输入上限 64K UTF-16 字符，输出上限 256K 字符，响应传输上限 4M 字符。对话历史仅保存在当前结果窗口内，累计请求内容上限 256K UTF-16 字符；关闭窗口或发起新的 AI 操作即丢弃，不会写入设置文件。追问会把原始选区和当前窗口内的对话再次发送给所配置的服务。不会自动重试，不跟随接口重定向。

## 配置与兼容性

“设置 → 常规 → 外观”提供跟随系统、亮色和暗色，默认跟随系统。工具条默认仅显示图标，悬停图标可查看操作名称。工具条空闲透明度可在同一区域选择（10%–100%，默认 35%）。开启 Windows 动画效果时，半透明工具条的边框会有一段微光缓慢绕行。鼠标移入时工具条变为完全不透明，微光停止。

“设置 → 常规 → 划词行为 → 工具条显示位置”可选择上方或下方，默认上方。位置以划词结束时的鼠标位置为基准（快捷键唤起时使用当前鼠标位置）；靠近屏幕边缘时自动换到另一侧，并限制在屏幕工作区域内。保存后下次唤起即生效。

AI 结果窗口默认在失去焦点 5 秒后关闭。切回窗口会取消倒计时。点击“追问”后，当前窗口不再自动关闭并显示输入框；尚未进入追问模式的结果窗口仍遵循该设置。可在“设置 → 常规 → AI 结果窗口”关闭初始窗口的自动关闭。
AI 和智能操作的结果都在圆角窗口中显示。拖动标题栏可以移动窗口，拖动边缘可以调整大小，按 Esc 可关闭窗口。AI 结果窗标题栏显示操作名和模型名。
同一处也可选择已安装的字体和字号（默认 13），在设置中预览并保存。

在“设置 → 提示词 → 工具栏图标”中，每个 AI 操作默认使用 Emoji，可选择 Emoji 或 Nerd Font，并实时预览。Emoji 可粘贴或用 `Win + .` 输入，支持肤色和组合序列；当前 WPF 字体渲染可能显示为单色，以预览为准。Nerd Font 可粘贴单个字符或填写 `U+F121`、`0xF0001` 等码点，再选择已安装的 Nerd Font；留在“自动选择”会使用检测到的字体。可从 [Nerd Fonts 字符表](https://www.nerdfonts.com/cheat-sheet)查找字符。字体缺失或不含所选字符时回退为 ✨ Emoji；安装字体后需重启 PopBar。点击保存才生效，取消不会修改原配置。

配置文件：`%LOCALAPPDATA%\PopBar\settings.json`。密钥加密值也在此文件中，仅同一个 Windows 用户能够解密；不要把此配置提交到 Git。默认排除常见密码管理器，密码框不读取；可以添加进程名排除应用。

Nerd Font 也可点击“搜索 / 选择图标…”离线浏览：按英文名称（如 `translate`、`code`）、码点或粘贴的字符搜索，点击图标填入，悬停查看名称。仅展示所选字体包含的图标，分页显示以保持响应速度。输入框使用所选字体显示粘贴的字符，也接受 `\uF121`、`\udb81\uddca` 和 `\U000F05CA` 转义格式。内置约 522 KB 的 [Nerd Fonts v3.4.0 名称索引](https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/glyphnames.json)，不附带字体或新增运行库；上游许可随应用分发于 `Assets/nerd-font-LICENSE.txt`。

Windows 没有统一的“主选区”。自动划词通常通过应用提供的 UI Automation TextPattern 读取。PowerPoint 和 MarkText 也支持通过各自提供的选区接口读取高亮文字。部分浏览器、Electron、PDF 阅读器、远程桌面、画布或管理员窗口可能不支持。快捷键兜底也要求应用支持 Ctrl+C，且剪贴板没有被其它软件占用。临时复制可能被系统剪贴板历史或第三方剪贴板工具记录，即使当前剪贴板随后恢复。

自动识别的 UIA 调用最多等待 1.5 秒，同时最多一个读取任务；异常提供程序卡住时其它取词会被忽略，可退出并重新启动 PopBar。快捷键被其它软件占用时会给出托盘提示。

首版未移植 PopClip 扩展市场、脚本扩展、长按空白处粘贴或系统朗读。

## 开发与验证

输出目录约定：日常使用始终运行 `dist/PopBar-win-x64/PopBar.exe`，由 `./scripts/publish.ps1` 更新；分发包固定为 `dist/PopBar-win-x64.zip`。发布前先从托盘退出该程序。`src/`、`tests/` 下的 `bin/` 和 `obj/` 仅用于编译与测试，`artifacts/` 仅存放日志、截图和测试素材，不作为程序交付目录。

需要 .NET 8 SDK。

```powershell
dotnet build src/PopBar -c Release
dotnet run --project tests/PopBar.Tests -c Release
./scripts/test-selection.ps1
./scripts/publish.ps1
```

`PopBar.Tests` 使用内存模拟 HTTP 服务验证 SSE、中文编码、失败/截断/超限、取消、DPAPI 和请求格式，不访问真实 AI 服务。`test-selection.ps1` 会短暂打开自己的 WPF 测试窗口，通过真实 UI Automation 验证可编辑/只读/空/密码选区，以及原选区改变后的替换保护。

可手动启动测试窗口：`dotnet run --project tests/PopBar.Fixture`。建议在日常使用的浏览器、编辑器和 PDF 阅读器中分别试一次普通划词、快捷键取词和 AI 替换；也建议检查不同缩放比例的多显示器。真实服务调用需要用户自行配置，当前自动化测试未消耗 API 额度。

实现参考：[Windows TextPattern](https://learn.microsoft.com/en-us/dotnet/framework/ui-automation/ui-automation-textpattern-overview)、[Win32 鼠标钩子](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)、[Chat Completions 流事件](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events)。
