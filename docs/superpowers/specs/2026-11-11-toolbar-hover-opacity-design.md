# 工具条悬停透明度设计

日期：2026-11-11
状态：已批准

## 意图

工具条出现时半透明，避免遮挡选区后面的内容；鼠标进入可视区域时完全不透明，便于阅读和点击，离开后恢复半透明。

## 目标

- 空闲透明度 0.35，悬停 1.0，120ms 淡入淡出。
- 透明度作用于可见胶囊（根 `Border`），阴影和按钮一起变化。
- 半透明状态仍然可以点击；透明边距和窗口布局不变。
- 每次 `Present` 重置为空闲状态，避免上一次悬停残留。

## 非目标

- 除空闲透明度外，不增加其他透明度调节 UI。
- 不做自动隐藏、延迟消失或按钮级独立透明度。
- 不改变工具条定位、按钮、点击后隐藏等现有行为。

## 方案

- 在 `ToolbarWindow` 的根 `Border` 上设置 `Opacity`，`MouseEnter` 动画到 1，`MouseLeave` 动画回 0.35；`Present` 开始时停止动画并设为 0.35。
- 备选：改 `Window.Opacity`（会把透明边距一起算入，视觉差异不大）；瞬间切换（更简单但生硬）。选择 Border + 短动画。
- 使用 WPF `DoubleAnimation`，120ms，EaseOut。

## 验证

- `UiChecks`：首次 `Present` 后透明度为 0.35；触发 `MouseEnter`/`MouseLeave` 后存在透明度动画；再次 `Present` 重置动画与空闲透明度。
- 生成 toolbar 截图检查空闲状态。
- 构建、测试、发布通过。

## 留给实现

- 确认真实鼠标从工具条移入/移出时动画流畅；自动化测试只验证动画已启动和状态重置，不等待动画结束。

## 修订：空闲透明度可配置（2026-11-12）

- 新增持久化设置 `ToolbarIdleOpacity`，默认 35%，允许 10%–100%，按 5% 步进选择。
- 设置界面放在“常规 → 外观”，显示为百分比；100% 时空闲与悬停均为完全不透明。
- `ToolbarWindow` 每次 `Present` 读取并限制该值；悬停仍淡入到 100%，移出恢复到配置值。
- 旧配置没有该字段时继续使用 35%。
